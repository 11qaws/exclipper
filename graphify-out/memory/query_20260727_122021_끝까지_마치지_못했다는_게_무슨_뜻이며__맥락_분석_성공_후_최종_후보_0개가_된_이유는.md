# Q: 끝까지 마치지 못했다는 게 무슨 뜻이며, 맥락 분석 성공 후 최종 후보 0개가 된 이유는 무엇인가?

## Answer

방송 전체 맥락은 성공했지만 후보별 Pass B가 candidatePassBRun.status=failed로 종료되어 최종 검증 전에 중단됐다. 13개 모두 탈락 판정을 받은 것이 아니다. 5개 context-missing은 맥락에서 의도적으로 제외된 후보를 App이 최종 reservoir에 남겨 오류로 오분류한 통합 버그이고, 나머지 8개 detail-result-missing은 insight 성공 콜백이 0회였다는 뜻이다. deepPass 37초는 성공 시간이 아니라 실패 상태 도달 시간이다. 단일 후보 오류가 mapWithConcurrency 전체를 중단시키는 fail-fast 구조가 피해를 8개로 확장한다. 실제 최초 원인은 현재 진단이 유실되어 스크린샷만으로 확정할 수 없으며, loadingModel 중 프레임 실패를 CANDIDATE_FAILED로 보내 reducer가 거부하는 상태 전이 오류와 아직 대용량 Base64 JSON을 쓰는 /v1/candidate-insights의 Free Worker CPU 초과가 유력하다. 다음 재현에서 요청 발생 여부와 wrangler tail CPU/1102를 함께 보존해야 확정된다.
