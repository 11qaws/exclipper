# Q: 오류가 정확히 8개 뜨고 다시 진행됐는데, 이거 나중에 재시도로 메꿔지는지 확인

## Answer

Expanded from original query via graph vocab: [transcript, broadcast, chunk, worker, audio, duration, sampling, concurrency, rate, payload, wav, qwen]. A browser-level CORS failure on /v1/broadcast-transcript is caught by broadcastTranscript.worker.ts as transcription-failed, added to gapChunkIds, and is not requeued in the same run; AdaptiveConcurrency only lowers concurrency and later chunks continue. Successful partials are checkpointed. On reload/reconnect, App subtracts persisted chapter ranges and schedules uncovered ranges, so the missing cells can be recovered without redoing successful paid cells. retryWholeContextPhase currently resets transcription only for failed or zero-chapter states, not completedWithGaps with chapters, so the in-session retry control does not refill these gaps and needs correction.
