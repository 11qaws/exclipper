# Q: 현재 들어온 영상에서 youtube 자막을 받아오는 로직은 어떻게 되지

## Answer

Expanded from original query via graph vocab: [youtube, caption, captions, track, request, proxy, worker, transcript, asr, source, input, broadcast]. 현재 작업 트리에서는 입력 파일명 끝의 [11자리ID] 또는 다시보기 주소에서 YouTube ID를 얻고, 수동 주소가 우선한다. 분석 시작 뒤 transcript phase에서 hidden opaque sandbox가 Android Innertube로 한국어 JSON3 자막을 먼저 받으며, 실패하면 Worker proxy, 다시 실패하면 빈 계획 셀만 VAD/ASR로 복구한다. 자막은 exact planned cells로 투영되고 셀별 receipt와 chapter는 IndexedDB session에 보존된다. 현재 배포본은 sandbox 변경이 아직 미배포라 Worker→ASR이다. 자동 동일영상 검색/내용 일치 검증은 없고, 수동 주소가 새 파일 선택 시 초기화되지 않는 결함과 3.33시간 초과 영상에서 전체 자막을 sampling cells에만 투영하는 제한이 있다.
