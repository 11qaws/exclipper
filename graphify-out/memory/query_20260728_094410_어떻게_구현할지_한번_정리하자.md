# Q: 어떻게 구현할지 한번 정리하자

## Answer

확장 질의: broadcast, transcript, speech, audio, qwen, provider, fragment, recovery, chapter, worker, quota, context. 구현 결론: 기존 broadcastTranscript.worker의 PCM 디코드 직후, WAV/R2/API 직전에 Silero VAD를 보수적 3상태(speech/no-speech/uncertain)로 삽입한다. 확실한 무발화만 ASR에서 제외하고 영상 분석은 유지하며, uncertain/VAD 오류는 ASR로 fail-open한다. 현재 dialogue chapters가 완료 범위 역할까지 겸하므로 session 1.4에 canonical evidence/coverage ledger를 추가하고 dialogue projection을 분리한다. no-speech는 정상 완료이지 gap/chapter가 아니며, 전 구간 무발화도 visual-only로 정상 완료한다. provider-neutral transcript result를 만들고 Groq whisper-large-v3와 Qwen3-ASR adapter를 붙인다. free-first 정책은 Groq 무료 쿼터를 Durable Object가 조직 단위로 예약하고 명확한 429/거절/한도 소진만 Qwen3-ASR로 fallback한다. outcome-unknown은 중복 호출하지 않고 상태를 보존한다. 기존 free-R2 URL 통로를 재사용하고 qwen3.5-omni는 영상·맥락에만 둔다. docs/state migration, shadow VAD, high-confidence skip, ASR A/B, canary, 5-session load 순으로 적용한다.
