# Q: 파이프라인 분석해서 이걸 정상화하자

## Answer

전체 맥락 후보는 protocol 상한 32개, 상세 AI 후보는 비용 상한 12개로 분리했다. 후보별 화면 준비와 AI 해석 실패는 settled 방식으로 격리하며, 저장된 context packet·4개 화면·thumbnail·insight·verification receipt가 모두 현재 맥락 fingerprint와 일치할 때만 최종 후보로 출판한다. 정상적으로 검증 후 제외된 0개는 completedEmpty이고, 실제 증거 누락만 pipeline gap으로 남긴다. Candidate Free 경로는 브라우저가 WAV와 JPEG 4장을 private R2 bundle로 올리고 Worker는 capability URL만 Qwen에 전달한다. 맥락 또는 증거가 불완전하면 durable stage cursor를 앞당기지 않는다.
