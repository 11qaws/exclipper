# ui-forms — 공용 표시 폼

특정 화면에 속하지 않는 모양들. 한 화면에서 잘 나온 폼을 그 화면 안에 두면 다음에
같은 것이 필요할 때 다시 만들게 된다.

**실물 목록**: `dev/forms.html` — 생성은 `npx tsx dev/gen-forms.mjs`
(이 CSS 파일을 그대로 링크하므로, 목록이 라이브러리에 없는 것을 보여 줄 수 없다.)

---

## 지금 있는 것

| 폼 | 무엇 | 언제 쓰나 | 쓰지 않을 때 |
|---|---|---|---|
| `uf-notch` | 양쪽 끝이 접힌 텍스트 카드 | 구역 이름표, 시각·기간 딱지 | 문단·긴 설명 — 잘린 모서리가 글줄을 먹는다 |
| `uf-split` | 제목 │ 설명 | 뒤가 앞을 한정하는 짝(날짜/요일, 단계/상태, 이름/역할) | 대등한 두 값 — 없는 종속 관계를 말하게 된다 |
| `uf-row` | 사이드 리스팅 한 줄 | 고르는 대상이 자기 색·그림을 가진 목록 | 텍스트뿐인 목록 — 색과 그림이 없으면 이득이 없다 |

### 변형

```
uf-notch--ribbon    양 끝이 화살 모양. 흐름 위의 한 점(시각·기간)
uf-notch--start     왼쪽만 접힘. 오른쪽이 열려 있어야 할 때
uf-notch--outline   테두리만
uf-notch--quiet     약한 표면색. 부차적인 딱지
uf-split--accent    가르는 선을 테마색으로. 현재 위치 표시 — 한 화면에 하나
```

---

## 붙이는 법

토큰 일곱 개만 이어 준다. 아무것도 안 이어 줘도 기본값으로 그려진다.

```css
.my-panel {
  --uf-accent:     var(--ex-accent);
  --uf-accent-on:  var(--ex-accent-on);
  --uf-ink:        var(--ex-ink);
  --uf-ink2:       var(--ex-ink2);
  --uf-surface:    var(--ex-bg);
  --uf-surface2:   var(--ex-bg2);
  --uf-line:       var(--ex-line2);
}
```

`uf-split` 이 좁은 자리에서 세로로 쌓이게 하려면 **부모에**
`container-type: inline-size` 를 켠다. 화면 폭이 아니라 놓인 자리의 폭을 보기
때문이다 — 같은 폼이 넓은 본문에도 좁은 사이드시트에도 들어간다.

---

## 지켜야 하는 규칙 (별도 저장소로 떼어낼 수 있게)

1. **접두사 `uf-` 만.** 앱 클래스와 절대 겹치지 않는다.
2. **바깥 토큰에 의존하지 않는다.** 모든 색은 `var(--uf-*, 기본값)`.
   `--ex-*` 를 직접 참조하는 순간 이 폴더는 이 앱 전용이 된다.
3. **JS 없음.** 상태는 클래스나 `[aria-*]` 로만.
4. **크기는 `em`.** 부모의 `font-size` 하나로 전체가 따라 커진다.
5. **대비는 계산으로.** 반투명 배경 위의 글자는 눈으로 가늠할 수 없다.

### 5번이 실제로 잡은 것

`uf-row` 의 설명 글자를 흐린 단계(`ink3` 류)로 두었더니 **라이트 전 테마에서
4.5:1 아래**로 떨어졌다(실측 3.21–4.12). `ink3` 는 평평한 배경 기준으로 잡힌
색이라, 틴트를 얹은 배경에서는 근거가 사라진다. `ink2` 로 바꿔 최저 5.82.

그래서 `uf-row` 는 **글자를 사진 위에 두지 않는다.** 사진 위 대비는 사진 내용에
따라 흔들려 계산으로 보장할 수 없다. 사진은 오른쪽에서 흘러나오고, 글자 쪽은
합성색이 평평하게 덮는다.

---

## 나중에 별도 저장소로 뺄 때

이 폴더(`ui-forms.css` + 이 문서)와 `dev/gen-forms.mjs` 를 옮기면 된다.
생성기에서 팔레트 모듈 의존만 걷어내고 고정 색 몇 벌로 바꾸면 독립한다.

새 폼을 넣을 때는 위 표의 **"쓰지 않을 때"** 칸을 반드시 채운다. 언제 쓰지
말아야 하는지가 없는 폼은 결국 아무 데나 쓰이고, 그때부터 폼이 아니라 장식이
된다.
